# 오늘의 에오르제아

이 PC에서 혼자 쓰는 FFXIV 숙제·목표 관리 앱. 기존 시트와 연결하지 않으며 빈 목록에서 시작합니다.

## 열기

바탕화면의 **오늘의 에오르제아** 아이콘을 두 번 클릭합니다. 또는 이 폴더의 `launch.vbs`를 실행합니다. 터미널을 따로 켤 필요 없습니다.

처음 준비할 때만 Node.js 22 이상이 필요합니다. 현재 PC의 Node.js를 사용하며 외부 패키지 설치는 없습니다. 다른 PC에서는 [Node.js 공식 홈페이지](https://nodejs.org)에서 LTS를 설치한 후 실행합니다.

## 사용법

1. **콘텐츠 추가** → 이름 → **저장하기**. 활성 여부와 ID는 입력하지 않습니다.
2. 매일/매주 할 일은 추가 창의 **반복**을 선택합니다. 기본은 반복 없는 장기 목표입니다.
3. **오늘 할 일**의 왼쪽 체크를 누르면 완료됩니다. 완료한 목록을 펼치면 취소할 수 있습니다.
4. 석판 등은 **수량 채우기**로 추가합니다. 대시보드의 숫자를 입력하고 Enter 또는 다른 곳을 누르면 저장됩니다. 목표를 450에서 900으로 바꾸려면 이름 클릭 → 수정 → 목표 수량만 바꿉니다. 현재 수량은 유지됩니다.
5. 동전 3종은 **여러 항목 체크**로 만들고 레이드 이름을 각각 적습니다. 이름 또는 `···` 클릭, 또는 우클릭하면 상세창에서 각각 체크할 수 있습니다.
6. 설명과 링크는 **더 설정하기**에 적습니다. 목록에는 이름과 최소 정보만 표시합니다.
7. 목록/카드 보기, 일일/주간/장기 필터, 이름 검색, 상단 고정을 사용할 수 있습니다.
8. 당분간 하지 않을 항목은 상세 → **보관하기**. 전체 콘텐츠 → **보관함**에서 다시 꺼낼 수 있습니다.

시작 화면의 900개 석판과 동전 3종은 **선택형 입력 예시**입니다. 게임의 현재 패치 규칙을 자동으로 조회하지 않습니다. 이름·수량·반복은 직접 변경할 수 있습니다. 기존 시트의 캐릭터, 목표, 완료 기록은 가져오지 않았습니다.

## 반복 규칙

- 기본값: 매일 00:00, 매주 화요일 17:00, 매일 05:00. 모든 시간은 한국 시간(Asia/Seoul) 기준입니다.
- **반복과 설정 → 규칙 추가**에서 매일/매주/매월/며칠마다와 시각을 직접 정합니다.
- 매월 31일은 31일이 없는 달에 말일로 처리합니다. 며칠마다는 기준 시작일과 간격을 사용합니다.
- 시간이 지나면 체크·현재 수량·세부 체크가 초기화됩니다. 완료 기록은 남습니다.
- 앱을 꺼두었어도 다음 실행 시 지난 주기를 반영합니다. 실행 중 화면은 최대 30초마다 갱신됩니다. 열린 입력창은 자동으로 덮어쓰지 않으며 경계 직후 저장 요청은 최신 상태로 다시 시도하도록 안내할 수 있습니다.
- 반복 규칙을 수정할 때 현재 체크는 보존하고 새 규칙의 다음 시간부터 초기화합니다. 규칙을 공유한 모든 콘텐츠에 적용됩니다.
- 쿠로 수첩의 별도 수령/제출 기한, 패션 체크 입장 가능 시간 같은 게임 전용 로직은 없습니다. 필요한 이름과 반복 시간으로 관리합니다.

## 저장·백업

- 데이터: `data/state.json`. 브라우저 캐시를 지워도 이 파일은 유지됩니다.
- 앱 실행 시 `data/backups/`에 자동 백업, 최근 30개 보관.
- **반복과 설정 → 백업 내보내기**로 JSON 파일을 별도 보관할 수 있습니다.
- **백업 복원**은 전체 목록을 교체합니다. 교체 직전 데이터는 `data/backups/*-before-restore.json`에 별도 보관됩니다.
- 데이터와 로그는 GitHub에 올리지 않습니다. GitHub 저장소는 앱 코드 보관용이며 데이터 동기화 기능은 없습니다.
- 여러 창에서 동시에 바꾸면 오래된 화면의 저장을 거절하여 덮어쓰기를 막습니다.
- 저장 파일을 읽을 수 없으면 덮어쓰지 않고 시작을 중단합니다. 파일을 보존한 뒤 `data/backups/`의 정상 백업을 복사해 복구할 수 있습니다.

창을 닫아도 작은 저장 프로그램이 남습니다. **반복과 설정 → 앱 완전히 종료**로 종료합니다. 다음 실행 때 다시 켜집니다. 자동 시작 프로그램 등록은 하지 않습니다.

## 개발

```sh
node server.mjs
node --test
```

로컬 주소: `http://127.0.0.1:17414`. 내 PC의 루프백 주소에서만 수신하며 인터넷에 공개하지 않습니다. 테스트용 별도 데이터 경로는 `FFXIV_DATA_DIR`, 포트는 `FFXIV_PORT`로 지정합니다. 별도 인증 키 파일이나 외부 서비스 계정은 필요 없습니다.

UI는 로컬에 설치된 Pretendard가 있으면 사용하고, 없으면 맑은 고딕으로 표시합니다. 외부 폰트/CDN을 호출하지 않습니다.
